# Sign-In Screen

This folder contains the Sign-In Screen design for the application.

## Purpose

The Sign-In Screen provides the initial interface for users to access the application. After signing in, the system will eventually determine the user's role and display the appropriate navigation and functionality.

## Design Tool

Figma was used to create the Sign-In Screen design.

## Screen Elements

* Application name and logo
* Username or email field
* Password field
* Sign-In button
* Forgot Password option
* Registration or account creation option, if required

## Sprint Cycle I

The Sign-In Screen is a UI design deliverable for Sprint Cycle I. Authentication and other application functionality are not implemented during this sprint.
